# מאפיית לחם ושמש

אתר סטטי למאפייה בשכונת הדר בחיפה, עם טופס הזמנת משלוחים שנשלח לוורקפלואו ב־n8n.

**חי בכתובת:** https://lehem-veshemesh-bakery.vercel.app

## הקבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | כל תוכן האתר |
| `style.css` | כל העיצוב. נייד תחילה, שתי נקודות שבירה, בלי אנימציות |
| `assets/order.js` | שליחת הטופס לוובהוק, ובדיקות בצד הלקוח |
| `assets/images.json` | מפת התמונות ב־Cloudinary |
| `assets/images/` | עותקי המקור של הלוגו ותמונות המוצרים |

אין שלב בנייה ואין תלויות. Vercel מחובר ל־main ופורס כל דחיפה.

התמונות נטענות מ־Cloudinary ולא מהריפו. להחלפת תמונה מעלים קובץ חדש לאותו
public id, והאתר מתעדכן בלי שינוי קוד.

## תוכן ושפה

התוכן מוגבל למה שהופיע במייל של הלקוח. אין נתונים מומצאים, אין סופרלטיבים,
ואין מקפים בתוך טקסט עברי. כותבים "ראשון עד חמישי" ו"06:30 עד 08:30".

## מסלול ההזמנה

```
טופס באתר
  -> POST JSON
  -> n8n webhook  https://shanyptr.app.n8n.cloud/webhook/bakery-order
       workflow "Lehem veshemesh bakery", id cJPSnFcFFZlcM19B
  -> Guard          סינון. מכאן ממשיכה רק הזמנה שעברה את כל הבדיקות
  -> Edit Fields    חישוב מספר הזמנה, סכום ותאריך אספקה
  -> Google Sheets  שורה בגיליון ההזמנות
  -> Gmail          אישור ללקוח, וסיכום למאפייה
  -> תשובה לאתר     {ok, order_id, total, delivery_date}
```

האתר מציג הודעת הצלחה רק כאשר חוזר `ok:true`, כלומר אחרי שההזמנה כבר נשמרה
ושני המיילים יצאו.

## שכבות ההגנה

הטופס פתוח לכל מי שמוצא את כתובת הוובהוק, ולכן הסינון קיים בשתי שכבות. השכבה
בדפדפן מונעת רעש, והשכבה בוורקפלואו היא זו שמגנה באמת.

### בדפדפן, `assets/order.js`

- שדה מלכודת בשם `lehem-note`, מוסתר ב־clip-path ולא ב־display none
- זמן מילוי מינימלי של 2500 מילישניות
- דקה המתנה בין שליחות, ולכל היותר חמש שליחות בשעה, נשמר ב־localStorage
- חלון הזמנות 07:00 עד 20:00 שעון ישראל, וחלה רק ביום חמישי

מי ששולח POST ישיר לוובהוק עוקף את כל אלה.

### בוורקפלואו, נוד `Guard`

| בדיקה | תנאי |
|---|---|
| מלכודת | `lehem-note` חייב להיות ריק |
| שדות חובה | שם, טלפון, מייל, כתובת |
| אורך שדות | שם עד 80, מייל עד 120, כתובת עד 200 תווים |
| מייל | מבנה תקין |
| טלפון | בין 9 ל־15 ספרות |
| כמויות | מספר שלם בין 0 ל־20 לכל מוצר |
| הזמנה | לפחות פריט אחד, וסכום 40 שקלים ומעלה |
| שעות | 07:00 עד 20:00 שעון ישראל |
| חלה | רק בהזמנה שנשלחת ביום חמישי |
| אותו לקוח | לא יותר מהזמנה אחת ב־5 דקות, ולא יותר מ־3 ביממה |
| תקרה כללית | 40 הזמנות בשעה |

זיהוי הלקוח לצורך התקרה הוא צירוף המייל והטלפון. הספירה נשמרת ב־static data
של הוורקפלואו ומתנקה אוטומטית אחרי 24 שעות.

הזמנה שנדחתה מקבלת תשובה מיידית, `400` לשגיאת תוכן ו־`429` לחריגת קצב, ולא
מגיעה לגיליון ולא מייצרת מייל. כשהתקרה הכללית נחצית נשלחת התראה למאפייה, פעם
בשעה לכל היותר, כדי שהתיבה לא תיסתם.

להעלאת התקרות משנים את הקבועים בראש הנוד `Guard`.

## מה עדיין זמני

- פרטי הקשר הם דמה: `lehem@example.co.il` ו־04-1234567. הם מופיעים באתר וגם
  בשתי תבניות המייל בוורקפלואו, ולכן החלפה דורשת עדכון בשלושה מקומות
- תמונות המוצרים והלוגו נוצרו במחשב ומחכות לצילומים אמיתיים
- תרשים אזור החלוקה סכמטי ולא לפי קנה מידה
- ב־`allowedOrigins` של הוובהוק עדיין רשומים דומיינים של localhost מימי הפיתוח
